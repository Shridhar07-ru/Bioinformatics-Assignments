# Assignment 2 – Differential Gene Expression Analysis

## Objective

Perform differential gene expression (DGE) analysis using a publicly available GEO dataset and visualize the results.

## Tasks

- Download gene expression dataset from GEO
- Load and preprocess expression data
- Perform differential gene expression analysis
- Identify significantly differentially expressed genes
- Generate:
  - Volcano Plot
  - Heatmap
- Export differentially expressed genes as CSV
- Interpret the biological significance of the results
