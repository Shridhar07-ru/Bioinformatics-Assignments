# Assignment 1 – NCBI Sequence Analysis

## Objective

Retrieve the TP53 mRNA sequence from NCBI and perform sequence analysis using Biopython.

## Tasks

- Fetch TP53 mRNA (NM_000546)
- Save sequence as FASTA
- Parse FASTA using SeqIO
- Calculate:
  - Sequence length
  - Nucleotide composition
  - GC content
- Parse GenBank file
- Extract metadata
- Interpret biological significance
