# Assignment 3 – CRISPR Guide RNA Design

## Objective

Design guide RNAs (gRNAs) for a target gene using the CHOPCHOP v3 web server and evaluate their efficiency and specificity.

## Tasks

- Select a target gene for CRISPR analysis
- Design guide RNAs using CHOPCHOP v3
- Evaluate guide RNA efficiency
- Analyze GC content and self-complementarity
- Assess predicted off-target effects
- Select the most suitable guide RNA
- Interpret the biological significance of the results
